# MSBA Class Directory

Live page: https://msba-students.github.io/class-directory/

## Add yourself (GitHub Desktop)

1. **File → Clone repository → URL** → `MSBA-Students/class-directory`.
2. **Current branch → New branch** → name it `add-<yourfirstname>`.
3. Open `index.md` in your editor. Add **one row at the bottom** of the table:
   `| Your Name | [you.github.io](https://you.github.io) | a fun fact |`
4. Back in Desktop: write a summary (e.g. `Add Fadel to directory`) → **Commit to add-…** → **Publish branch**.
   Desktop will ask how you plan to use this fork → choose **"To contribute to the parent project"**.
5. Click **Create Pull Request** → fill in the template → **Create pull request**.
6. Swap with a neighbour: open their PR → **Files changed** → leave one comment → **Review changes → Approve**.
7. After the instructor merges: Desktop → switch **Current branch** to `main` → **Fetch origin** → **Pull origin**. Your row is there.

`main` is protected: nobody (including the instructor) can push to it directly. That is the point.
